# 🧪 Laboratorio #3 - Validación de Usuario (Página Supercines)

Este proyecto consiste en un pequeño script en JavaScript que simula la validación de un usuario en una página web. Es parte de un ejercicio de laboratorio para practicar el manejo de objetos, funciones y validaciones básicas.

## 📋 Descripción

El código define un objeto `usuario` con las propiedades:
- `nombre`: Nombre del usuario (puede contener espacios).
- `correo`: Correo electrónico usado para acceder.
- `contrasena`: Contraseña del usuario.

La función `validarUsuario(usuario)` se encarga de verificar:
1. Que el correo sea igual al esperado y no esté vacío.
2. Que la contraseña también coincida y no esté vacía.

Si las validaciones son correctas, se muestra un mensaje de bienvenida con el nombre del usuario.

## 💡 Tecnologías Usadas

- Lenguaje: **JavaScript (ES6)**
- Entorno: **Navegador o Node.js**
